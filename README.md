# Xodarap

Site institucional e sistema com painel administrativo para uma empresa de tecnologia, construído com **Node.js + Express**, templates **EJS** e banco **Supabase**.

## Funcionalidades
- Página institucional (`index`) com apresentação da empresa
- Login e autenticação (`login`)
- Painéis de dashboard e administração (`dashboard`, `admin`, `admin-dashboard`)
- Gerenciamento via banco Supabase

## Tecnologias
Node.js · Express · EJS · Supabase · JavaScript · CSS

## Como rodar
1. Instale as dependências: `npm install`
2. Configure as variáveis de ambiente (banco Supabase) conforme o `.env` local
3. Inicie o servidor: `node server.js`

> **Nota:** o arquivo `.env` e `node_modules/` não fazem parte do repositório.
